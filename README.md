# Python ARP Table Reader

A simple Python learning project that reads the local ARP table and extracts detected IP addresses.

## What it does

- Runs the `arp -a` command
- Reads the ARP table output
- Extracts IP addresses
- Displays the detected IP addresses

## What I practiced

- Python
- Computer Networking
- ARP
- IP addressing
- Loops
- The `subprocess` module

## How to run

```bash
python3 my_scanner.py
```

Built as a learning project while practicing Python and networking fundamentals.
